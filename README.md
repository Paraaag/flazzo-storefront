# FLAZZO Storefront

A Next.js storefront for freshly milled wheat atta, delivered in Mahalunge, Pune.

## Features

- Three wheat varieties, 2 kg and 5 kg packs, and custom grind preferences
- Cart checkout with cash or UPI payment on delivery
- Guest order tracking and an admin order dashboard

## Run locally

```bash
npm install
npm run dev
```

Built with Next.js, React, TypeScript, Drizzle ORM, and Netlify Database and Identity.
